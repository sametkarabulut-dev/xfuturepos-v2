# Araç Kutusu

## İlke
- İşletmelere **araç** veriyoruz. Ortak çekirdek tüm sektörlerde bir kez durur.
- Sektör / alt sektör araçları o sektörün ağacında durur.
- İşletme türü = araçların birleşimi. Açık API yoksa panel kaydı + kullanıcı girişi.
